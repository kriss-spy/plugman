# Domain Documentation

Plugman is a single-context repository.

Before implementation or ticket work:

1. Read `CONTEXT.md` for canonical domain language.
2. Read `docs/product-spec.md` for accepted user behavior.
3. Read `docs/architecture.md` for module interfaces and seams.
4. Read relevant records under `docs/adr/`.

Use glossary terms in issue titles, tests, and code. Do not substitute words explicitly listed under `_Avoid_` in `CONTEXT.md`.

If proposed work contradicts an ADR, state the conflict rather than silently overriding it. Historical brainstorm documents are not normative when they conflict with the product specification or accepted ADRs.
